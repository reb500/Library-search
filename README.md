# Library-search
A call to an API  to retrieve results for a book search using the authors name, title of a book or a subject.

git clone https://github.com/reb500/Library-search.git
cd Library-search
npm install
npm start

At the start of the program the options are 1, 2 and 3, you type any of those values.
To search you will enter one string the last name, first name of the author or a subject word or one word of the title.
2, Displays a list of saved books while the program is running.
3, exist the program.


The API used is assigned to a URL: https://openlibrary.org/search.json?
